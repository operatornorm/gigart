RE6 Mercenaries Patch - desktop Linux / native Steam Proton preview.3

STATUS
The Windows v0.2.2 release is confirmed by the user and stays unchanged:
https://github.com/operatornorm/gigart/releases/tag/v0.2.2
This separate preview needs its first live RE6/Proton verification. Automated
checks pass with Wine and a synthetic 32-bit process; they do not run RE6 or Steam.

REQUIREMENTS
First requested live target: Artix Linux with Proton Experimental selected for RE6.
- Desktop Linux x86-64 with native Steam and RE6 installed (app 221040).
- The supported original v1.1.0 executable, SHA-256:
  b8bceaf09272d5f30b89940737763afa6dfb78647c81165af1aa8a10d0afeb35
- Python 3.10 or later (standard library only for the Linux launcher).
- Native Protontricks, including its protontricks-launch command. Install it
  through your distribution or follow the upstream instructions:
  https://github.com/Matoking/protontricks#installation
  Use a current version supporting the installed Proton Experimental build.
- A normal 64-bit Proton prefix for RE6, already initialized by Steam.

FIRST TRIAL
1. Extract this complete archive outside the game folder. Keep all its files
   together. Turn other trainers off; restart RE6 if one was active.
2. Start RE6 normally from Steam using the Proton version selected for RE6.
   Stay outside any lobby or round. No particular screen/menu is required.
3. Open a terminal in the extracted folder and run. For the confirmed dual-boot
   layout on the first Artix test machine, select the native copy explicitly:

   bash ./run-proton.sh --steam-dir "$HOME/.local/share/Steam" --game-dir "$HOME/.local/share/Steam/steamapps/common/Resident Evil 6"

   With exactly one registered RE6 installation, bash ./run-proton.sh is enough.

4. In the patch window, click Refresh. If the supported game is recognized and
   Apply is enabled, click Apply. Save diagnostics afterward for the first trial.
5. Create a fresh standard Mercenaries lobby. Save another diagnostic there,
   without starting a round, to check six-slot initialization under Proton.
6. Close RE6 to undo the memory patch, or leave the lobby and use Restore.

No additional human players are needed for this first Linux compatibility
check. Keep the diagnostic JSON files for the developer. The original Windows
three-player gameplay result does not establish Proton multiplayer behavior.

HOW IT LAUNCHES
The Linux script finds the native Steam library and checks the exact game hash.
It then uses protontricks-launch --appid 221040 to run the bundled Windows helper
inside RE6's existing Proton environment. It supplies the actual native library
path using Proton's standard Z: mapping. The helper uses the same tested patch
bytes, code/context guards, inactive-session checks, suspended transaction,
readback and rollback. It does not change game files, saves, timer, game mode,
Steam checks or Steam registry paths. Closing RE6 discards the patch.

CUSTOM PATHS / TROUBLESHOOTING
- For a nonstandard native Steam client root:
  bash ./run-proton.sh --steam-dir "/path/to/Steam"
- When Steam lists both a native Linux installation and a mounted Windows copy,
  select the folder
  opened by Steam's Browse local files:
  bash ./run-proton.sh --game-dir "/path/to/Steam/steamapps/common/Resident Evil 6"
  --steam-dir selects the Steam client root; --game-dir selects the game folder.
- If preview.1 reports it cannot find exactly one copy, but Steam Browse local
  files shows ~/.local/share/Steam/steamapps/common/Resident Evil 6, try:
  bash ./run-proton.sh --steam-dir "$HOME/.local/share/Steam"
  This selects the Steam client root, not the Resident Evil 6 game folder.
- To check paths and print the command without launching the helper:
  bash ./run-proton.sh --dry-run
- A custom STEAM_COMPAT_DATA_PATH must be set to the same path used for RE6.
- Preview.3 uses a direct WoW64 PEB32 query for the 32-bit game image, avoiding
  the module-list call suspected in the Wine 11 WinError 998 report. Image base,
  size, executable hash and live code/context checks still apply. Diagnostics
  record the stage and module-query details on any remaining failure.
- Preview.2 and later compare executable file identity rather than path text, so Wine
  drive aliases of the same registered file are accepted. An independent copy
  with identical bytes is still rejected. Failed Refresh checks can now be
  exported with Save diagnostics, including the actual/registered image paths.
- If the helper cannot see an already-running game, confirm Protontricks uses
  the same Proton version/prefix as Steam. Do not add this helper as a separate
  non-Steam game; that creates a different prefix. Do not run it using system
  Wine, as root, or using sudo. No ptrace setting changes are required.
- If a game hash differs or code is already modified, it is refused. Do not
  substitute a different hash or enable other trainers to get past the check.
- No Wine/proton DLL overrides, prefix migrations, package installation or
  game launch-option edits are performed by this launcher. Protontricks/Wine
  may perform their ordinary prefix/runtime setup when starting an application.

This first preview targets native Steam. Flatpak Steam, Flatpak Protontricks,
Steam Deck Gaming Mode and custom pure-32-bit prefixes are not covered.
The Linux launcher requires Python and Protontricks; its bundled Windows helper
includes its own Python runtime. It does not download or install dependencies.
